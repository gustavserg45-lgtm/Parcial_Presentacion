# Fuentes originales del trabajo

El equipo dispone localmente de los siguientes materiales aportados en ChatGPT:

- Enunciado del Parcial 2 / Hackathon InfraTech: San Luquitas Digital.
- Manual Docker Fedora 44 (7 ejercicios): referencia pedagógica, **no** requisito de ejecutar los siete ejercicios.
- Manual de iniciación Docker Fedora 37: comandos antiguos que deben revisarse antes de usar en Fedora actual.
- Plantilla APA 7.ª edición: originalmente UNAD; adaptar portada a UNAB.

**No se suben los originales al repositorio público**, porque pueden contener datos de personas y material de terceros. Las obligaciones y la estructura del trabajo están resumidas en `docs/01-requisitos.md` y `docs/05-informe-apa.md`. Si Codex necesita un dato no documentado, debe indicar qué página o información falta y consultar la copia local sin publicar el contenido privado.
